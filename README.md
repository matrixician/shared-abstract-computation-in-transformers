

This project is designed to test the conditions under which (and whether) transformers form shared circuits for the same underlying computation but which are represented across disparate domains. 
The 'shared abstract computation' is the comparison operator, but which can later include more operators such as symmetry, succession, rotation, etc. 

# Experiment 1
Experiment 1 tests one claim: when a transformer performs the same abstract operation on different input domains, part of its causal computation is shared, and that shared part sits in a bounded band of layers between domain-specific encoding and decoding.
